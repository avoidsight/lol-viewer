# 客户端重要更新提示

正式安装版通过 GET https://lol.19950919.me/api/releases/latest 获取后台已有公开版本协议；开发和fixture默认不联网、不显示假版本。后台已有important标记，无需新增迁移或服务端部署。

- 线上最高已发布版本数字x.y.z大于app.getVersion()即显示右上角“新版本”，包括普通更新。不是字符串比较，不提示同版、旧版；最新版非重要时不回溯寻找旧重要版本。
- 启动页面检查，页面可见时每30分钟检查，重新聚焦/可见时最短5分钟检查。主进程另有5分钟缓存、并发合并；8秒超时、32KiB流式上限、禁止重定向、失败静默隐藏。不影响战绩请求、不调用窗口聚焦。
- 普通更新仅按钮；重要更新在应用可见且有焦点、阶段已确认为None/Lobby/EndOfGame、无其他模态框时自动显示一次。未知阶段、选英雄、排队、游戏内等阶段等待安全时机。复用现有游戏阶段，不增加LCU轮询；前台30秒轻量检查是否可弹窗。
- 按钮始终可手动查看版本号和纯文本更新日志，不渲染HTML/远程脚本。取消或Esc只关弹窗，本次启动同一版本不再自动弹。手动打开也记为本次已提醒。
- “该版本不再提示”存本机Electron用户数据下的localStorage，键lol-viewer:ignored-update-versions，保留最近100个忽略版本。仅禁用该版本自动弹窗，按钮仍可手动查看，不影响其他新版；清除应用用户数据会丢失此偏好。保存失败明确提示而不假称已忽略。兼容上一版已忽略版本：恢复其按钮但不自动弹。
- 更新按钮只提交版本号给主进程；主进程重新检查发布状态及版本匹配，仅允许官方https域名下/downloads/UUID，通过系统浏览器下载EXE。不会自动安装、退出应用、模拟输入或强制更新。撤下、被新版替代、网络失败显示可重试提示。
- 无额外设备/玩家信息随检查上报。现有设备统计和反馈协议不变。

发版：客户端先设置正确的新版本号并打包，后台创建同版本草稿、填写更新日志、勾选重要更新、上传EXE并发布。已装版本必须包含本功能才会提示；旧安装版需先手动升级一次。

验证：数字版本比较、重要标记、非官方URL/超大响应/失败保护、请求去重、撤下与替代保护、取消/忽略/新版重现、下载失败提示；Electron使用替换IPC的合成版本，不访问生产安装包。Windows系统浏览器下载/安装覆盖尚未实机验证。
