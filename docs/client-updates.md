# 客户端更新提示与应用内下载安装

正式安装版通过 GET https://lol.19950919.me/api/releases/latest 获取后台已有公开版本协议；开发和fixture默认不联网、不显示假版本。后台已有important标记，无需新增迁移或服务端部署。

- 线上最高已发布版本数字x.y.z大于app.getVersion()即显示右上角“新版本”，包括普通更新。不是字符串比较，不提示同版、旧版；最新版非重要时不回溯寻找旧重要版本。
- 启动页面检查，页面可见时每30分钟检查，重新聚焦/可见时最短5分钟检查。主进程另有5分钟缓存、并发合并；8秒超时、32KiB流式上限、禁止重定向、失败静默隐藏。不影响战绩请求、不调用窗口聚焦。
- 普通更新仅按钮；重要更新在应用可见且有焦点、阶段已确认为None/Lobby/EndOfGame、无其他模态框时自动显示一次。未知阶段、选英雄、排队、游戏内等阶段等待安全时机。复用现有游戏阶段，不增加LCU轮询；前台30秒轻量检查是否可弹窗。
- 按钮始终可手动查看版本号和纯文本更新日志，不渲染HTML/远程脚本。取消或Esc只关弹窗，本次启动同一版本不再自动弹。手动打开也记为本次已提醒。
- “该版本不再提示”存本机Electron用户数据下的localStorage，键lol-viewer:ignored-update-versions，保留最近100个忽略版本。仅禁用该版本自动弹窗，按钮仍可手动查看，不影响其他新版；清除应用用户数据会丢失此偏好。保存失败明确提示而不假称已忽略。兼容上一版已忽略版本：恢复其按钮但不自动弹。
- 「下载更新」只提交版本号给主进程，不再打开浏览器，也没有浏览器兜底。主进程重新检查发布状态及版本匹配，仅从官方HTTPS域名下/downloads/UUID下载EXE，禁止重定向。沿用服务端已有size/sha256，无需后台修改、迁移或部署。
- 弹窗显示百分比和已下载/总大小；可取消、失败重试或「后台下载」。关闭弹窗/Esc不终止下载，再次打开恢复当前状态，刷新渲染页面也从主进程恢复。不支持断点续传；取消或退出后重新下载。
- 文件流式写入系统临时目录lol-viewer-updates下本次独占download-*目录，先package.part，再校验实际大小、MZ文件头和SHA256，成功后改名setup.exe。最多250MiB；30秒无数据/总计30分钟超时；进度事件最多每200ms一次，完成立即通知。失败/取消删除本次临时目录，不把整个安装包读进内存。
- 下载完成不退出、不安装、不抢焦点；用户可以「稍后安装」。只有点击「退出并安装」才重新核实线上版本、下载地址、大小、摘要并复核本地文件SHA256，然后通过Electron shell.openPath启动该本地安装包，启动成功才app.quit。权限确认被拒绝或启动失败时保留App和安装包，可重试；撤回/替换/损坏的包不执行。
- Windows沿用现有NSIS安装向导覆盖安装，不是静默安装。可能出现系统UAC/SmartScreen或安装器确认；用户自行确认安装和完成后的启动选项。不会模拟按键、关闭游戏或强制更新。SHA256只保证与发布文件一致，不替代代码签名/安全扫描。
- 仅Windows正式安装版允许下载/执行；macOS、开发和fixture不可触发真实安装。IPC逐个鉴权和校验，渲染进程只提交版本号，不接收或指定本地路径/任意URL/安装参数。安装启动后临时包留给安装器读取；系统临时目录可能残留已完成的安装包，可由系统临时文件清理处理。
- 无额外设备/玩家信息随检查上报。现有设备统计和反馈协议不变。

发版：客户端先设置正确的新版本号并打包，后台创建同版本草稿、填写更新日志、勾选重要更新、上传EXE并发布。已装版本必须包含本功能才会提示；旧安装版需先手动升级一次。

验证：数字版本比较、重要标记、元数据校验、非官方URL/超大响应保护、去重、流式下载/取消/超时、截断/超大/损坏包清理、安装前撤下/替代/篡改保护、启动失败不退出、IPC鉴权及桥接校验；Electron以替换IPC的合成版本验证下载进度、后台下载、取消/重试、稍后安装、独立安装确认、忽略、新版提醒和无浏览器调用。合成安装包不会执行，不访问生产包、不增加生产下载量。Windows NSIS覆盖安装、权限提示与实际设置保留仍需新包实机验证。

接入依据：[Electron shell.openPath](https://www.electronjs.org/docs/latest/api/shell#shellopenpathpath)；安装器配置沿用apps/desktop/package.json的NSIS target。用户需要先手动安装包含本功能的新包一次，之后发布更高版本可走应用内下载；服务器手动上传EXE的流程不变。
