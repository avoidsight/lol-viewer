# 游戏内填入战绩（实验）

默认关闭，仅 Windows。设置中开启后，先到对战页加载本局战绩，再在游戏中按 Enter 打开聊天框，按下并松开 Ctrl + Alt + V，检查内容后自行按 Enter 发送。长摘要最多填入 180 个 UTF-16 单位（含省略号），这是本地保守上限，并非已验证的国服聊天长度。

## 实现和边界

- 摘要仅保留在主进程内存，与自动复制开关及剪贴板去重无关，不读取系统剪贴板。关闭后清空，重新开启需重新加载战绩。
- 快捷键触发后校验 LCU 当前 gameId、连接和 InProgress 阶段；助手就绪后再校验一次。只接受两小时内加载的数据；每次完成加载更新有效期。
- 固定 PowerShell 源码内嵌在主进程包中，Windows 自带 PowerShell 通过 Add-Type 编译小型 C# P/Invoke；不用下载 EXE，不需要用户安装 SDK。启动可能有短暂延迟。受策略限制无法执行时失败退出，不修改执行策略。
- 文本经 stdin 的 base64 数据传送，绝不拼进脚本或命令；无游戏注入、内存访问、自动回车、自动重试、额外网络服务。
- 只接受前台进程可执行文件名 `League of Legends.exe`，记录窗口与 PID；逐字符检查焦点和修饰键，使用 SendInput + KEYEVENTF_UNICODE 成对按下/抬起；支持 UTF-16 代理对。焦点切走、按住 Esc 或修饰键会停止，可能已填入部分内容。
- 每 3 秒最多一次，单任务在途；助手最多 8 秒，包含 LCU 检查的整个请求最多 12 秒。关闭/退出会取消并杀掉助手。快捷键冲突则拒绝开启，保留原复制功能。
- 前台游戏窗口不等于聊天框已打开，必须由玩家先打开。也无法检测聊天框内已有命令或文本，请在空聊天框操作。SendInput 返回成功仅代表事件进入系统输入队列，不证明游戏接收。系统权限、游戏版本和保护机制均可能影响结果。
- 不弹成功提示或自动发送。失败使用系统静默通知，不抢焦点；通知被系统关闭时可能看不到提示。

## Windows 手动验收（必须在发布前完成）

1. 用现有 Windows 打包入口生成测试包并安装；确认默认关闭，原复制与设置正常。
2. 自定义局中加载本局战绩，开启实验功能（若先加载后开启，重新加载），游戏空聊天框按快捷键。检查中文、标点、emoji、长度和延迟；确认不自动发送、不依赖剪贴板。首次先测试不要发送。
3. 测试未加载、另一局、对局结束、断开客户端、快捷键被占用；应不填入。
4. 输入时切出窗口、关闭开关、退出应用；验证停止、无残留 PowerShell。连续按快捷键不并发；失败后仍能使用复制。
5. 重启验证开关持久化；关闭后重新开启必须重新加载。安装旧版验证原设置和缓存可读。

当前 macOS 的类型检查、单元和 Electron UI 测试不代表 Windows PowerShell 编译、实际游戏输入或安装器验收。需要上述实机验证才能判断当前国服是否可用。

## 关闭与回滚

- 即时恢复：在设置中关闭「游戏内填入战绩（实验）」。不会改变「自动复制敌方战绩」开关。
- 紧急禁用：退出应用，以环境变量 `LOL_VIEWER_DISABLE_GAME_INPUT=1` 启动。启动时清除持久化开启值，不注册快捷键。
- 代码回滚：对本功能独立提交执行 `git revert <功能提交号>`，重新打 Windows 包安装。不要 reset 或恢复旧数据库。
- 数据库迁移 7 仅增加默认 0 的 `game_text_input` 列；旧版使用明确列名读写、忽略更高迁移版本，保留新列即可。无需删除列或恢复缓存，避免丢失之后的数据。回退前先关闭开关，避免未来再次升级时恢复此前开启值。
- 基线：开始实现时 cd44c64；期间另一任务提交了玩家搜索布局 66193ce / bd5576d。回滚仅 revert 本功能提交，保留这两个布局提交。
