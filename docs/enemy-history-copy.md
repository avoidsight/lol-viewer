# 自动复制敌方战绩

设置 → 游戏辅助 → 自动复制敌方战绩，默认关闭，开启后覆盖系统剪贴板。只写入文本，不读取剪贴板、不模拟键盘、不发送聊天、不抢焦点。

完成当前对局战绩加载后，使用已加载的敌方五人数据生成一行摘要：排位对局取已读取的单双/灵活排位最近最多10场，其他对局取全部模式。排除重开、重复记录，显示每人的实际场数和胜负；未知数据标注“暂无数据”，全部未知不复制，不新增评级。位置可靠时显示分路，否则只显示玩家ID。该功能不增加战绩查询或改变游戏中停止补全的策略。

必须能确认本方队伍、五名敌方以及非零gameId，且没有仍在loading的敌方。复制前重新读取游戏阶段和gameId，过期、取消、已结束或中途关闭开关均跳过。成功复制的最近100个gameId在本机SQLite去重，切页、筛选、重连及应用重启不重复写入；失败不影响对局显示。清战绩缓存不清此去重记录。剪贴板和SQLite不是跨资源事务，进程在写入与标记之间崩溃时不能保证严格一次。

开启不立刻复制已保留的上一局；在之后的正常加载完成时生效。关闭自动进入对战页时，需要手动进入对战页触发原有加载流程。没有可靠gameId、对面不可读取或游戏中加载被取消时不会为了复制继续查询。切换UI排位/全部筛选不会改变自动摘要，也不触发再次复制。

复制后应用内提示5秒，用户自己打开队伍聊天并粘贴发送；游戏输入长度与粘贴行为需Windows实测。较长摘要可能需要分段手动发送。fixture模式绝不复制合成数据。

验证：摘要/缺失数据、设置持久化、并发与重建去重、跨局/取消/关闭/异常测试，Electron设置和被动提示测试。真实Windows LCU与游戏内粘贴未验证。客户端须重新打包；不需要修改或部署后台。
