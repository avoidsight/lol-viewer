# 自动复制双方战绩

设置 → 游戏辅助 → 自动复制双方战绩，默认关闭，沿用旧版开关值，开启后覆盖系统剪贴板。此功能只写入文本，不读取剪贴板、不模拟键盘、不发送聊天、不抢焦点。

英雄选择ChampSelect阶段即可复制：五名己方战绩处理完毕先复制己方；敌方也就绪时更新成己方＋敌方摘要（两行），若双方同时就绪只复制一次。GameStart/InProgress/Reconnect也可触发。主进程保存加载过程中已完成的玩家快照，复用现有阶段检测，在游戏中停止补查时仍可使用已加载数据，不增加战绩查询。排位己方每人展示平均评分，敌方重点玩家同样展示平均评分（0–100，保留一位小数）；沿用rankedForm有效样本门槛，不足标注评分不足，非排位不强行评分。己方全部不可用时保留敌方单独复制能力，之后己方可用可升级为双方。

完成当前对局战绩加载后，使用已加载的敌方五人数据生成一行摘要。排位局按统一综合评分提示最多两名重点玩家，优先显示当前英雄名，缺失时回退玩家ID；至少三名对手可评估才比较，候选均分至少70，第一名领先第二名至少8分时只显示第一名。不足五人可评估时明确“仅比较已知战绩”；没有突出选手和样本不足分别提示，不强行选大腿。复用页面的小代/通天代标签，不以胜率单独判断。详见 uniform-performance.md。

其他对局保留全部模式胜负摘要，未知数据标注“暂无数据”，全部未知不复制。位置可靠时显示分路，否则只显示玩家ID。功能不增加战绩查询或改变游戏中停止补全的策略；英雄名只加载一份 LCU 静态目录并共享缓存，失败60秒内不重试，不逐玩家请求。

必须能确认本方队伍、五名不同己方以及非零gameId，且己方没有仍在loading的玩家；敌方摘要仍要求完整双方阵容。复制前重新读取游戏阶段和gameId，过期、已结束或中途关闭开关均跳过。成功复制在本机SQLite按gameId及己方阶段后缀去重（保留最近100条），双方版本复制后不退回己方版本，切页、筛选、重连及应用重启不重复写入；失败不影响对局显示。清战绩缓存不清此去重记录。剪贴板和SQLite不是跨资源事务，进程在写入与标记之间崩溃时不能保证严格一次。

开启不复制上一局；当前有效对局已有记录可在下一次阶段检测时复制。关闭自动进入对战页时，需要手动进入对战页触发原有加载流程。没有可靠gameId不复制；对面不可读取或游戏中加载被取消时不会为了复制继续查询，但已加载的己方快照可复制。切换UI排位/全部筛选不会改变自动摘要，也不触发再次复制。

复制后应用内提示5秒，用户自己打开队伍聊天并粘贴发送；游戏输入长度与粘贴行为需Windows实测。较长摘要可能需要分段手动发送。fixture模式绝不复制合成数据。

验证：摘要/缺失数据、设置持久化、并发与重建去重、跨局/取消/关闭/异常测试，Electron设置和被动提示测试。真实Windows LCU与游戏内粘贴未验证。客户端须重新打包；不需要修改或部署后台。
