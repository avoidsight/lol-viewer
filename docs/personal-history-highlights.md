# 个人战绩文字标签

个人战绩阵容头像悬停只显示玩家的 displayName（有 Riot tag 时为 name#tag），不拼接“查看…的个人战绩”；点击跳转不变，不为缺失的 tag 编造编号。

每场最多三个文字徽章，不再使用难以识别的纯图标。稳定顺序为：CARRY、超神、本场最高多杀、最高输出、最高承伤。只渲染有数据的项目，空标签栏不占位；MVP、经济、助攻、击杀、补刀、死亡等其他标签不显示。

- 超神依据客户端 stats.largestKillingSpree >= 8，不根据总击杀猜测；IPC/缓存保留该可选字段，个人历史缓存版本升级为10。
- 多杀沿用实际 largestMultiKill 或相应击杀次数数据。
- 个人战绩不展示 MVP，即使旧缓存或测试数据带有该字段也忽略，不能把模拟字段视作真实接口能力。
- CARRY 复用对战页排位算法：单双/灵活排位，非重开且至少10分钟，参团率>=55%、KDA>=3、每10分钟死亡<=2.5，关键数据缺失不评估。悬停说明为本应用评估，不等同掌盟官方评级。
- 全场最高指标要求至少10个参与者且该指标对每人均有数值，本人值>0且等于最大值，允许并列。资料不全或更少人数模式保守不颁发“最高”标签。

样式参考掌盟的可读文字徽章，但保留应用深色主题。徽章紧凑、按类别配色，窄列自动换行，整场保持桌面横向布局。相关单测、真实Electron fixture测试覆盖标签上限、超神边界、未知数据、局部阵容、旧缓存刷新和头像跳转。
