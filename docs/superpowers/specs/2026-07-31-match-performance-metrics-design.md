# 战绩装备与表现指标设计

## 目标

- 战绩装备栏固定为每排 3 件，最多两排展示 6 件装备。
- 用伤害、承伤、金币三项表现指标替换补刀与纯金币文本。

## 数据

- 对英雄伤害：`totalDamageDealtToChampions`。
- 承受伤害：`totalDamageTaken`。
- 获得金币：`goldEarned`。
- 每项占比均使用本人所在队伍所有参与者的对应数值合计作为分母。
- 分母为 0 或完整队伍详情不可用时，不生成占比。

## 界面

- 三项指标纵向排列，依次使用用户提供的橙色、绿色、金色图标。
- 图标以原始 18×18 尺寸放入固定容器并水平、垂直居中。
- 数值和整数百分比合并显示为 `78k(23%)`。
- 装备栏在桌面和中等宽度保持 3 列，不隐藏第 4 至第 6 件装备。
- 极窄窗口继续隐藏整个次要数据区，避免破坏主要战绩信息。

## 验证

- 适配层测试覆盖三项己方占比。
- 渲染测试覆盖三种图标、数值、百分比以及 3 列装备布局规则。
- 完整测试、类型检查、生产构建、Windows 打包和 SQLite 冒烟测试通过。
