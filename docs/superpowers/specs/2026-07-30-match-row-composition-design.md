# 战绩行阵容改版设计

## 目标

将个人战绩行右侧的“全场最高”徽章替换为双方阵容，并在本人的英雄与装备信息附近展示两个召唤师技能。

## 数据

- 从 LCU 历史对局参与者读取 `teamId`、`championId`、`spell1Id`、`spell2Id`。
- `MatchSummary` 新增可选的 `summonerSpellIds`、`allyChampionIds`、`enemyChampionIds`。
- 当前参与者所在队伍为己方，其余队伍为敌方；各队最多保留 5 个英雄。
- 新字段保持可选，旧缓存仍能解析并显示，只在缺失位置展示空位。

## 界面

- 删除战绩行右侧的全场最高徽章区域。
- 两个召唤师技能使用 CommunityDragon 图标，紧邻 KDA/装备区域。
- 最右侧展示两行阵容：上排己方、下排敌方，每排 5 个小头像。
- 当前玩家的英雄头像使用强调边框。
- 日期、明确标注的“时长 X 分钟”、装备、CS 和金币保持不变。

## 验证

- 适配器测试覆盖队伍拆分和召唤师技能映射。
- IPC schema 测试覆盖新增字段。
- 页面测试覆盖技能图标、两排阵容、高亮本人以及徽章移除。
- 完整测试、类型检查、Electron 构建和 SQLite 冒烟测试通过后重新生成 portable 包。
