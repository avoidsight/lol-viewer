# 玩家战绩搜索

个人战绩顶部输入完整“名字#编号”，点击搜索或回车，解析当前大区玩家身份后复用个人战绩页。返回我的战绩功能不变。必须登录英雄联盟客户端；不支持跨区或模糊搜索，不通过后台代理。

主进程固定调用 POST /lol-summoner/v1/summoners/aliases，JSON 数组传入 gameName/tagLine。校验响应字段和完整别名匹配后才交给原战绩查询；空数组或无匹配显示未找到，连接/鉴权失败提示登录，其余失败不冒充未找到。输入、响应在 IPC 两侧校验，主进程限制单个查询在途，不暴露通用 HTTP 调用给渲染器。LCU JSON POST 使用原五秒超时、响应大小限制和本地连接。

不按键触发网络请求，不增加后台轮询。身份请求结束后沿用战绩缓存、SGP/LCU 数据源和详情补齐逻辑。搜到身份但战绩无法获取时由原页面显示不可用。fixture 返回合成玩家，不访问线上。

验证：类型检查、身份解析/输入/HTTP JSON/IPC授权与并发测试及 Electron 搜索→个人战绩→返回流程。macOS 模拟通过不代表国服当前接口可用；Windows 需验证本人、同区其他玩家、不存在ID及未登录场景。接口不可用时明确报错，不绕过隐私或权限限制。
