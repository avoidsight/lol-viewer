# 微信赞赏

客户端版本 1.0.0 新增“支持作者”入口，位于反馈旁。仅点击后展示图片，不自动弹窗，不限制功能，也不处理支付或统计金额。

- 正式安装版启动及可见时每分钟读取 `https://lol.19950919.me/api/donation`；重新聚焦时最短间隔 30 秒。开发/fixture 不访问生产接口。
- 默认关闭；配置异常时隐藏入口。打开时再次检查开关，只读取当前 revision 图片，不持久缓存图片。后台修改不是推送，已有弹窗在下一次配置检查后关闭。
- 主进程固定 HTTPS 地址、禁止重定向、8 秒超时、限制响应体积；渲染进程无上传/修改权限。
- 新后台需先部署 DonationSettings 数据库迁移及 API；管理员在 `/donation` 上传图片，确认收款人后开启。没有后台新 API 时客户端静默隐藏入口。
- 用户必须安装新 Windows 包；无需自动升级，当前包版本仍为用户选定的 1.0.0。

验证：网络/异常/体积单测、React 弹窗测试、Electron 模拟数据测试。Windows 安装版及真实微信扫码需另验；测试截图内应用图标仅为占位，并非付款码。
