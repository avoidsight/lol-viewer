# 战绩兼容性修复

- 对战 LCU 请求层与适配器统一支持 games 数组及 games.games 嵌套响应，避免请求层提前拒绝。
- LCU/SGP 历史的可选字段校验失败时视为缺失（包括 null、空身份及无效技能编号），不生成虚假统计值。核心胜负、英雄、K/D/A 仍校验。
- 每场独立解析，混合响应保留有效比赛；非空响应全部无效则报错，真正空列表正常返回。统计仅基于有效比赛。
- 个人缓存版本 12。手动刷新通过 IPC 传递经校验的强制刷新标志，绕过新鲜缓存；失败不回退旧缓存为成功，由页面保留已有内容并 toast 提示。
- 对战已知玩家暂时失败时每 15 秒补查，同 gameId 最多 3 次；沿用并发 4 及成功缓存，排除隐藏占位与隐私限制，离页/结束取消计时。次数在本次应用运行内保留。
- 本地测试验证响应结构、空可选字段、部分/全部异常、刷新和重试上限。macOS 合成数据验证不代替 Windows 真实 LCU 联调。
