# 战绩兼容性修复

## 2026-10-15 SGP 响应大小与失败分类

- SGP 战绩 SUMMARY 包含全体玩家与扩展统计，20 场正常格式响应可能超过 2 MiB；战绩读取上限单独调整为 16 MiB，段位等其他远程读取仍为 2 MiB。保留 8 秒超时、禁止重定向、声明长度及实际流式字节数两层限制；不取消读取保护、不增大查询并发。
- SGP 401/403 表示授权或查询权限异常，不凭状态码认定为玩家隐私，也不通过其他来源绕过权限拒绝。404 视为数据未就绪，可尝试既有 LCU 备用来源；明确的隐私限制与 429 仍不回退。
- 对战单玩家错误分类与个人刷新采用相同规则，不再把任意 403/404 显示为玩家未公开。
- 回归使用纯合成的 20 场大于 2 MiB 响应（有/无 Content-Length）、超限响应、401/403/404/429 与明确隐私错误。不包含真实玩家数据；不是 Windows 游戏客户端实测。

- 对战 LCU 请求层与适配器统一支持 games 数组及 games.games 嵌套响应，避免请求层提前拒绝。
- LCU/SGP 历史的可选字段校验失败时视为缺失（包括 null、空身份及无效技能编号），不生成虚假统计值。核心胜负、英雄、K/D/A 仍校验。
- 每场独立解析，混合响应保留有效比赛；非空响应全部无效则报错，真正空列表正常返回。统计仅基于有效比赛。
- 个人缓存版本 12。手动刷新通过 IPC 传递经校验的强制刷新标志，绕过新鲜缓存；失败不回退旧缓存为成功，由页面保留已有内容并 toast 提示。
- 手动刷新遇到可自行恢复的故障（超时、客户端不可用、数据未就绪、5xx）时按 250/750 毫秒各重试一次；授权失效、限流、隐私限制、结构不兼容不重试。普通加载保持单次请求语义。
- 失败原因区分未登录、数据未就绪、超时、限流、未公开战绩、结构不兼容等；主进程只记录脱敏的原因码、来源与 HTTP 状态码，不记录响应体、路径或令牌。
- 客户端未完成登录时给出的负数或缺失头像视为默认头像，不再让整次读取失败。
- 对战已知玩家暂时失败时每 15 秒补查，同 gameId 最多 3 次；沿用并发 4 及成功缓存，排除隐藏占位与隐私限制，离页/结束取消计时。次数在本次应用运行内保留。
- 本地测试验证响应结构、空可选字段、部分/全部异常、刷新和重试上限。macOS 合成数据验证不代替 Windows 真实 LCU 联调。

## 2026-10-14 加载稳定性

- 不支持的国服 SGP 大区配置回退为本机 LCU 查询，避免创建可选远程客户端时使两个战绩页面一起失败。
- 游戏阶段查询临时失败会保留已知阶段和正在加载的玩家，不伪报为 `None`，也不取消或重复发起战绩查询。明确退出对局、断开客户端和换局仍按原流程处理。
- SGP 请求及响应读取使用 8 秒超时、2 MiB 上限；LCU 增加 10 秒总等待上限及响应中断处理，避免一直等待没有完成的响应。
- 战绩读取在统一边界校验；一个来源超时、不可用或格式异常时尝试另一个可用来源。显式鉴权、隐私限制和限流不会触发备用查询。个人页只请求最近 20 场，不再请求 40 场后丢弃一半。
- 英雄选择中敌方名单尚未公开时补匿名占位，允许先显示己方；隐藏身份不发起玩家查询。身份出现后重新加载该阵容，历史缓存仍复用；新身份不继承旧玩家的战绩，其他局的迟到阵容不会覆盖当前局。
- 个人战绩列表与单局详情分离：列表不批量请求 20 场详情，右侧仅按选中比赛补查，120 毫秒内连续切换合并为最后一次选择。离页、刷新或切换比赛会取消旧详情请求；迟到结果不覆盖当前比赛。详情失败只在右侧提示，提供独立重试，左侧分页与刷新保持可用。
- 段位、版本与装备元数据最多等待 1.5 秒，失败或未完成时先显示真实战绩列表，已在途的元数据仍遵守底层请求上限。元数据缺失不伪造数值。
- 个人缓存版本 13，简洁列表可正常复用；详情更新不延长列表新鲜期，也不会覆盖更晚的刷新。无法确认当前账号时不把其他玩家的最新缓存当成本人。单局详情按 PUUID/召唤师身份定位，身份缺失时只接受唯一匹配的英雄及 K/D/A，不能确认则保留原列表并报错。
