# 使用统计

正式安装版启动窗口后延迟 10 秒异步提交 `POST https://lol.19950919.me/api/telemetry`。
开发及 fixture 不发送。请求最多 8 秒；网络/5xx 最多额外重试两次（30 秒、120 秒），4xx 不重试。跨北京时间自然日补报，休眠恢复检查日期，无高频轮询。

仅 JSON 字段：deviceId、clientVersion、osName、osVersion、arch。deviceId 与反馈相同，为应用命名空间哈希；不上传原始硬件编号、主机名、玩家账号或战绩。不把 deviceId 当登录凭证或真实人数。

设置 → 隐私 → 使用统计，默认开启，可随时关闭。关闭取消定时任务和进行中的请求（已送达服务器的数据无法撤回），不影响游戏功能或提交反馈；已有数据不自动删除。本地清理战绩缓存不会重置选择。

客户端版本来自安装包元数据。发版前应正确设置版本号；当前仓库版本 0.0.0 未在此次功能中擅自变更。Windows 实际安装包和跨系统设备稳定性仍需实机验证。
